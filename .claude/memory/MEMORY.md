# Palette Knot — 설계 결정 기록

프로젝트의 "왜"를 남기는 곳. 코드만 봐서는 알 수 없는 의사결정·맥락을 기록한다.

## 브랜드
- **Palette Knot**: 한국 전통 매듭 팔찌 + 컬러테라피. 어머니와 함께하는 사업.
- 초기 출시: 와디즈 써머 기획전.

## 디자인 결정
- **오방색(五方色) 채택**: 청靑·적赤·황黃·백白·흑黑. 한국 전통 색 체계 → 브랜드 정체성.
- 베이스는 한지빛(#faf7f0) + 먹빛(#2b2b2b)으로 미니멀하게, 오방색은 포인트로만.
- 폰트: Noto Sans KR (한글 가독성).

## 아키텍처 결정
- **로그인/DB 없음 (MVP)**: 단방향 플로우(테스트→결과→와디즈)라 Supabase 불필요.
  - 사진은 정적 파일(`public/`) + `next/image`로 서빙.
  - 어머니 직접 콘텐츠 편집(CMS)은 와디즈 이후 Sanity 추가 검토.
- **Claude API는 라우트 핸들러 경유**: 키 노출 방지 (`/api/color-test`).
