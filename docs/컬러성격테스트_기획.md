# 한국 전통매듭 팔찌 — 컬러 성격 테스트 기획·데이터 (7색 · 코칭 프레임)

> 사용자가 테스트를 하면 **"내 안에 많은 컬러 / 적은 컬러"**를 알려주고,
> 그에 맞는 **전통매듭 실 팔찌 컬러**를 추천하는 웹 테스트용 기획·데이터 문서.
>
> **참고 자료**
> ① 「좋아하는 색으로 알 수 있는 당신의 성격」(색채심리) — 색별 성격 유형
> ② 「울고 있지만 립스틱은 빨갛게」(컬러 코칭) — 긍정에너지·경계신호·체크리스트
> ③ 「12가지 컬러심리(긍정/부정)」 강의자료 — 단어(키워드)·긍정/부정·관계·확언 사례
> **제외:** ①의 p.14 '색 순서 해석표'(한국색채심리분석연구소, C-2013-008571), ③의 '에센셜오일' 표.
> ※ 팔찌는 **매듭 실로만** 제작하므로 보석·아로마 추천은 사용하지 않음.

### 색 통합 규칙 (12색 → 테스트 7색)

- **파랑(blue)** = 파랑 + **인디고(남색)** + **터콰이즈(하늘색)** 통합
- **핑크(pink)** = 핑크 + **마젠타** 통합
- 나머지: 빨강 · 주황 · 노랑 · 초록 · 보라 는 그대로.

---

## 1. 컨셉 개요

- **핵심 전제:** 좋아하는 색 = 성격·심리 상태의 거울.
- **테스트 목적:** 답변을 컬러 점수로 환산 → **많은 컬러(=지금의 나)**와 **적은 컬러(=보완하면 좋은 면)**를 보여준다.
- **상업 연결(매듭 실 팔찌):**
  - "많은 컬러" 팔찌 → 나를 표현·강화
  - "적은 컬러" 팔찌 → 부족한 기운을 채워 균형
  - 팔찌 태그·패키지에 각 색의 **확언 문구**("나는 ○○ 에너지입니다") 인쇄 → 감성 굿즈화
  - 결과 후 "이번 주 에너지 충전 컬러" 추천 → 재구매 유도

## 2. 컬러별 데이터

### 🔴 빨강 (red)
- **정체성:** "레드는 살아 있음 그 자체. 뜨겁고, 지금 이 순간을 사는 색."
- **키워드:** 지구·물질세계(땅·현실), 에너지, 어머니, 생존, 돈
- **많은 사람:** 에너지와 활력이 넘치고 행동력이 있다. 외향적·용감하며 자립적 의지가 강하다. 포용력이 있어 남을 크게 감싸며, 뛰어난 리더십으로 사람을 이끈다. 야심적이라 일에서도 성공하는 편. '정의의 빛'으로 상징된다.
- **적은 사람 / 그림자:** 지나치게 감정적이 되면 통제력을 잃고 정열이 분노로 바뀐다. 현재에 만족하지 못해 욕구불만이 쌓이고, 이기적·고집불통이 되거나 물질(돈·명예)에 집착. 무기력·권태에 빠지기도.
- **긍정 에너지:** 열정 · 용기 · 생명력 · 리더십 · 적극성(세상 일을 잘 관리) · 생각을 현실화하는 능력 · 타인에 대한 봉사와 자기희생
- **경계 신호:** 분노/화/증오/공격성 · 원망/무기력/피해의식 · 집착/미련/과거지향 · 에너지 고갈
- **관계 팁:** 활동 반경은 넓으나 자기 공간이 침범당하는 것을 두려워함. 어머니와의 관계와 밀접.
- **확언:** "나는 레드로부터의 육체적인 힘, 생명력과 의지력의 도움으로 용기를 냅니다. 레드의 지구력과 삶에 대한 열정이 나를 강하게 일으켜 줍니다. 나는 레드 에너지입니다."
- **How to Use:** 동기부여가 필요할 때 · 도전을 앞두고 용기가 필요할 때 · 무기력할 때 · 자신감을 되찾고 싶을 때
- **체크리스트:** 열정이 넘친다 / 결단력이 있다 / 행동력이 좋다 / 감정을 잘 조절한다 / 자신감이 있다 / 생명력을 느낀다
- **팔찌 추천:** 자신감과 행동력을 더하고 싶을 때.

### 🟠 주황 (orange)
- **정체성:** "오렌지는 삶의 즐거움과 존재의 기쁨을 꺼내는 색. 태양처럼 따뜻하다."
- **키워드:** 즐거움, 사교, 연결, 조화, 감수성, 파트너십
- **많은 사람:** 레드의 활력과 옐로우의 지혜가 연결된 색(정열 + 향상심). 밝은 에너지로 주변을 즐겁고 행복하게 만든다. 발랄·환하면서도 분석적이고 사려 깊어 신뢰받는다. 현실 감각과 융통성이 있고 감수성이 예민해, 감성을 쓰는 일에 잘 맞는다.
- **적은 사람 / 그림자:** 과거·현재의 감정적·육체적 충격을 놓지 못해 겁먹은 상태가 되기 쉽다. 자신감을 잃고 우유부단해져 타인에게 의존·비관적이 되며, 무엇이든 외부 탓으로 돌린다. 끈질기게 고집해 부담을 주거나, 부주의·경솔한 면도.
- **긍정 에너지:** 자존감 · 창조성 · 통찰력 · 유쾌함 · 가족애 · 적응력
- **경계 신호:** 자기 과시 · 애정 결핍 · 결정 장애 · 질투/자만 · 과소비 · 의존/트라우마
- **관계 팁:** 함께 즐기며 관계의 온도를 데우는 역할. 다만 의존과 보상 심리를 경계.
- **확언:** "나는 오렌지의 따뜻한 행복을 느낍니다. 솔직함과 자유로운 표현으로 구속되지 않는 변화의 바람을 느낍니다. 나는 오렌지 에너지입니다."
- **How to Use:** 자존감을 올리고 싶을 때 · 감정 표현을 하고 싶을 때 · 창의적 영감이 필요할 때 · 유쾌한 관계를 원할 때
- **체크리스트:** 사람들과의 만남이 즐겁다 / 감정 표현이 자유롭다 / 새 시도가 두렵지 않다 / 일상에 재미가 있다 / 관계에서 따뜻함을 주고받는다 / 어려움 속에서도 희망을 찾는다
- **팔찌 추천:** 침울할 때 기분을 릴렉스시키고 활기를 더하고 싶을 때.

### 🟡 노랑 (yellow)
- **정체성:** "옐로우는 깨달음과 희망의 빛. 마음을 비추는 햇살 같은 존재감."
- **키워드:** 인간(자아), 깨달음의 다리(bridge), 지성, 이해, 즐거움, 천진함, 명석한 두뇌, 희망
- **많은 사람:** 배움으로 얻은 지식과 명석한 두뇌를 지녔다. 사려 깊고 이해가 빨라 매사를 논리적으로 조립해 생각한다. 근면·성실·이지적이며 완벽주의자. 자립적 의지가 있어 주변에 안심감을 주고, 센스 있고 세련된 유머가 있다.
- **적은 사람 / 그림자:** 불안해서 사람을 의심하고 질투가 많아진다. 현재 상황이 주는 불안·공포에 사로잡히면 완벽주의·보수적이 되어 융통성이 없어진다. 억압된 감정을 아무 데서나 표출하거나, 날카로운 비판·빈정거림으로 흐르기도.
- **긍정 에너지:** 지식·지성 · 명석함/선견지명 · 기쁨/행복 · 호기심 · 희망 · 유머 · 발전성
- **경계 신호:** 겁/의심 · 집착/질투 · 계산적 태도 · 결정 장애(지나친 분석으로 판단 마비) · 정신적 스트레스(생각 과잉) · 남 탓 · 외로움/상실감
- **관계 팁:** 즉각적인 칭찬에 힘을 얻음. 이성적 사고나 단호한 결정이 필요할 때 옐로우가 도움.
- **확언:** "나는 옐로우의 태양빛 안에서 당당한 자신을 보며 평화를 느낍니다. 옐로우는 명료한 지적 호기심에 대한 소망을 밝혀 줍니다. 나는 옐로우 에너지입니다."
- **How to Use:** 새로운 것을 배우고 싶을 때 · 명료해지고 싶을 때 · 긍정 에너지가 필요할 때 · 웃음과 유쾌함이 필요할 때
- **체크리스트:** 새로운 것을 배우는 재미를 느낀다 / 아이디어가 자주 떠오른다 / 표현과 소통이 자연스럽다 / 호기심이 활발하다 / 실수를 학습으로 전환한다 / 유머와 가벼움이 있다
- **팔찌 추천:** 호기심·집중력을 높이고 밝은 기운을 더하고 싶을 때.

### 🟢 초록 (green)
- **정체성:** "그린은 평화와 성장의 색. 삶의 숨결이 머무는 공간."
- **키워드:** 마음, 공간, 방향성, 대인관계, 새로운 변화, 균형과 조화
- **많은 사람:** 균형과 조화의 사람. 360도 넓은 시야로 주변을 포근하게 하고, 있는 것만으로 사람을 편안·안심하게 한다. 문제를 싫어해 중립적 입장을 지키며, 자유분방하고 여행·모험을 좋아한다. 사람을 잘 돌보고 정신적 호기심이 풍부하며, 가야 할 길이 분명하면 결단을 밀고 나간다.
- **적은 사람 / 그림자:** 질투와 배신, 타인의 공간을 욕심내는 경향. 자기 감정을 지나치게 억눌러 어중간한 발언·태도를 취하고 책임을 회피, 감정·정서가 결핍된 상태가 되기도.
- **긍정 에너지:** 안정감/평화 · 성장 · 조화/수용 · 신뢰 · 협력/중재(분쟁 조정) · 치유
- **경계 신호:** 시기/질투/소유욕 · 고집/침체 · 무기력증 · 경계선의 결여(남의 공간에 있고 싶어함) · 감정 억제(분노를 안으로 눌러둠)
- **관계 팁:** "가슴에의 초대" — 마음을 열고 이야기하는 관계. 많은 사람이 과한 요구를 할 때 지치므로 경계를 지키는 연습.
- **확언:** "나는 그린에서 안전한 보살핌과 도움과 사랑의 도움을 받습니다. 세상의 친절함과 너그러움을 느낍니다. 나는 그린 에너지입니다."
- **How to Use:** 밸런스를 회복하고 싶을 때 · 새로운 변화를 시작할 때 · 감정적 안정이 필요할 때 · 관계에 신뢰와 평화를 더하고 싶을 때
- **체크리스트:** 삶의 균형감을 유지한다 / 스트레스를 건강하게 관리한다 / 자연에서 편안함을 느낀다 / 타인에게 위로를 준다 / 관계에서 안정감을 느낀다 / 내면의 평화를 실천한다
- **팔찌 추천:** 판단이 필요하거나 마음의 안정·균형을 회복하고 싶을 때.

### 🔵 파랑 (blue) — *인디고·터콰이즈 포함*
- **정체성:** "블루는 진실과 신뢰, 소통의 색. 깊은 교감과 내면의 질서를 이끄는 힘."
- **키워드:** 아버지, 신성, 권위, 커뮤니케이션, 책임감, 정신세계(하늘) / (인디고) 직관·통찰·무한한 가능성 / (터콰이즈) 창의력·예술성·방송·인터넷
- **많은 사람:** 평화와 소통의 사람. 온화하고 관용·자비심이 깊어 사랑받는다. 양심적이고 책임감이 강하며(장남·장녀가 많음), 자신을 드러내지 않고 공정해 큰 신용과 신뢰를 얻는다. 분석적·합리적이고 이해가 빨라 1:1 소통에 강하다. 타인을 치유·봉사하는 성향.
  - *(인디고)* 높은 영성·직관·통찰. 깊은 집중과 명상에서 평화를 찾고, 상황을 꿰뚫어 정확히 판단·결단한다. 사람과 적당한 거리를 두는 중립적 인간관계.
  - *(터콰이즈)* 창조적 커뮤니케이션(예술·미디어·방송). 직감을 믿고 변화에 잘 적응하는 낙관주의자, 좋은 의미로 어린이 같은 순수한 마음.
- **적은 사람 / 그림자:** 소통이 막혀 마음이 통하지 않는 허무감, 채워지지 않는 결핍. 고독·외로움으로 타인을 지나치게 간섭. 권위(아버지)에 대한 두려움·벽. 독단적·독선적이 되거나 사적 생활에 게을러짐.
  - *(인디고)* 균형이 깨지면 깊은 우울·자기불신·고립, 극단적 이상 추구와 현실 회피.
  - *(터콰이즈)* 마음의 벽·분리감·집착과 폐쇄, "난 항상 괜찮아"라며 거부도 수용도 안 함.
- **긍정 에너지:** 신뢰/신용 · 책임감 · 명료함 · 분석적 사고 · 인내력 · 평화로움 · (직관·통찰) · (창조적 소통)
- **경계 신호:** 집착/고정관념 · 권위적/독선적 · 수동성 · 슬픔/외로움 · 신경과민 · 인간관계 회피
- **관계 팁:** 즉시 칭찬에 힘을 얻음. 어머니 같은 포용(핑크)과 잘 어울림. 혼자만의 신비 세계로 빠지기 쉬우니 밖으로 나가 즐겁게 지내는 것이 도움.

## 3. 테스트 설계

### 3.1 점수 구조
- 7색을 각각 점수 차원으로 둔다. (파랑=파랑+인디고+터콰이즈, 핑크=핑크+마젠타 통합)
- 보기 1개 = 컬러 1개. **20문항 × 4보기 = 80보기**, 7색이 각각 **11~12회**씩 등장하도록 균형을 맞춤(특정 색 쏠림 방지).
- 종료 시 컬러별 합계 → 정규화(%) → 정렬. 상위 1~2색 = "많은 컬러", 하위 1~2색 = "적은 컬러".

```js
scores = { red:0, orange:0, yellow:0, green:0, blue:0, violet:0, pink:0 };
```

### 3.3 채점 로직 (의사코드)

```js
for (const answer of responses) {
  for (const color of answer.colors) scores[color] += 1;
}
const total = Object.values(scores).reduce((a, b) => a + b, 0);
const percent = Object.fromEntries(
  Object.entries(scores).map(([k, v]) => [k, Math.round((v / total) * 100)])
);
const ranked = Object.entries(scores).sort((a, b) => b[1] - a[1]);
const topColors    = ranked.slice(0, 2).map(e => e[0]);   // 많은 컬러
const bottomColors = ranked.slice(-2).map(e => e[0]);     // 적은 컬러
```

### 3.4 결과 화면 구성

1. **컬러 분포 그래프** — 7색 도넛/막대 차트(%).
2. **"내 안에 많은 컬러"** — 상위 1~2색: 정체성 + 많은 사람 + 긍정 에너지.
3. **그림자 살짝** — 그 색의 경계 신호를 1~2개만 부드럽게 언급.
4. **"내 안에 적은 컬러"** — 하위 1~2색 + 보완 포인트(How to Use).
5. **셀프케어 확언 카드** — 대표 컬러의 "나는 ○○ 에너지입니다" 확언(공유·팔찌 태그용).
6. **추천 매듭 팔찌** — 많은 컬러 팔찌(표현) + 적은 컬러 팔찌(균형).
7. **공유 버튼** — 결과 카드 이미지 SNS 공유.
